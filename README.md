# Do Attention-Based MIML Models Know Where Their Labels Are?

Code, benchmarks and stored results for

> Syed Umaid Ahmed, Muhammad Atif Tahir, Muhammad Waqas.
> *Do Attention-Based Multi-Instance Multi-Label Models Know Where Their Labels
> Are? An Attribution Protocol, a Ceiling Theorem, and a Pixel-Exact Benchmark.*
> Manuscript under review, 2026.

The repository is self-contained: every table and figure in the manuscript is
regenerated from the JSON result files in `results/instance_level/`, and a
verification script re-derives each numeric claim of the text from them.

## What is here

| Path | Contents |
|---|---|
| `miml_clam/` | Model package: instance embedding, contextual encoder, label-conditional gated attention, **hybrid attention pooling (HAP)**, correlation head, the two-phase trainer, and `metrics/instance_metrics.py` (the attribution protocol: P@k, chance rate, attribution AUC, label-agnostic ceiling). |
| `baselines/` | AB-MIL, Gated AB-MIL, TransMIL (lite), DSMIL, ML-Decoder, Q2L, each conforming to the same forward contract and exposing the attention tensor named in Table 4 of the paper. |
| `datasets/` | VOC-Patch construction: ResNet-50 patch features (`voc_miml.py`), pixel-exact patch labels from segmentation masks (`voc_patch_labels.py`, `build_voc_patch_gt.py`), and the VOC-Patch-Seg / -Seg-ML subsets (`build_voc_seg_subset.py`). |
| `run_instance_attribution.py` | The sweep driver: trains each (architecture, benchmark) cell and scores attribution on the same trained models. |
| `results/instance_level/` | The 35 result cells the paper reports (one JSON per cell, with the full run configuration and per-model attribution metrics). `_pre_transmil_fix_20260904/` holds the five TransMIL cells produced before the read-out fix described in `paper_attribution/REVISION_CHANGELOG.md`; they are kept for the record and not used. |
| `analysis/` | Table and figure generators, the statistical tests, and `verify_paper_claims.py`. |
| `data/MIML-SELFVIT/` | The three instance-labelled classical benchmarks (MSRC v2, Letter Frost, Letter Carroll) and the VOC-Patch fold permutations and patch-level ground truth. The two VOC-Patch feature files are release assets (see below). |

## Setup

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

PyTorch ≥ 2.0 with CUDA, Apple MPS, or CPU. The reported runs used Apple MPS.

## Data

The three classical benchmarks ship in `data/MIML-SELFVIT/`. The VOC-Patch
feature bags are too large for git and are attached to the GitHub release:

| Release asset | Size | Put it at |
|---|---|---|
| `voc2012seg.mat` | 298 MB | `data/MIML-SELFVIT/voc2012seg.mat` |
| `voc2012segml.mat` | 87 MB | `data/MIML-SELFVIT/voc2012segml.mat` |

Their fold permutations (`*_10CV.mat`) and pixel-exact patch labels
(`*_patch_gt.npz`) are already in `data/MIML-SELFVIT/`. To rebuild the
feature files from scratch instead (downloads PASCAL VOC 2012, runs a frozen
ImageNet ResNet-50 over a 4×4 patch grid; several hours):

```bash
python3 -m datasets.voc_miml                       # -> voc2012.mat (all trainval images)
python3 -m datasets.build_voc_patch_gt --thresh 0.05
python3 -m datasets.build_voc_seg_subset           # -> voc2012seg.*
python3 -m datasets.build_voc_seg_subset --multilabel-only   # -> voc2012segml.*
```

Set `MIML_DATA_DIR` to use a data directory elsewhere.

## Verification report

`VERIFICATION_REPORT.md` is generated by `analysis/make_verification_report.py`: environment, the live output of the claim verifier, every result cell with its file digest, the model-by-model theorem check, benchmark file digests, a configuration-uniformity audit across all cells, and an audit of the attention read-out. Regenerate it after any change.

## Reproducing the paper

Regenerate every table and figure from the stored results and check every
claim (takes under a minute; no training):

```bash
python3 analysis/make_attribution_tables.py --outdir paper_attribution/tables
python3 analysis/make_attribution_figures.py
python3 analysis/make_overview_figure.py
python3 analysis/attribution_stats.py --out paper_attribution/tables/attribution_stats.json
python3 analysis/make_setup_tables.py --outdir paper_attribution/tables
python3 analysis/verify_paper_claims.py            # must print "all checks passed"
python3 analysis/make_verification_report.py       # -> VERIFICATION_REPORT.md
cd paper_attribution && pdflatex main && bibtex main && pdflatex main && pdflatex main
```

Retrain a cell (results are idempotent per cell; pass `--rerun` to overwrite):

```bash
# classical benchmarks: 5 folds x 7 seeds = 35 models per cell
python3 run_instance_attribution.py --methods attnmil,gated_attn,transmil_lite,dsmil,ml_decoder,q2l,hap_only \
        --datasets letter_frost,letter_carroll,mscv2 --device mps

# VOC-Patch: 3 folds, one model per fold (the paper's protocol)
python3 run_instance_attribution.py --methods hap_only --datasets voc2012seg,voc2012segml \
        --device mps --folds 3 --no-ensemble
```

`--methods` accepts any of the six baselines or the HAP rows of
`run_alfapp_ablation.py` (`hap_only`, `hap_soft_only`, `hap_hard_only`,
`hap_fixed_half`). Training hyper-parameters are the defaults of
`run_all_enhanced.py` and are listed in Table 6 of the paper.

## The protocol on your own model

`miml_clam/metrics/instance_metrics.py` is dependency-free apart from NumPy:

```python
from miml_clam.metrics.instance_metrics import all_instance_metrics
m = all_instance_metrics(attn, inst_labels, bag_labels, mask=mask)
# attn        (B, L, N)  per-label attention over instances (need not be normalised)
# inst_labels (B, N, L)  per-instance ground truth
# bag_labels  (B, L)     bag ground truth
# mask        (B, N)     True at padded positions
# m: InstP@1, InstP@3, InstMRR, InstAUC, ChanceP@1, LabelAgnosticCeiling
```

`label_agnostic_ceiling` computes the bound of Theorem 1 for any dataset with
instance labels, before any model is trained.
